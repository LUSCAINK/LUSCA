# Code of conduct

LUSCA is built in the open by people with different backgrounds, skills and opinions. This document
sets the expectations for everyone who takes part: maintainers, contributors, neuron operators and
anyone posting in issues, pull requests or discussions.

## Expected behaviour

- Be respectful and assume good intent. Disagree with ideas, not with people.
- Keep discussion technical and on topic. Back claims with code, logs or measurements.
- Give and accept review constructively. Explain what should change and why.
- Respect people's time: search before opening an issue, and keep reports reproducible.
- Respect privacy. Do not post other people's personal data, wallet addresses tied to identities,
  or private messages without consent.

## Unacceptable behaviour

- Harassment, insults, threats or discriminatory language of any kind.
- Sexualised language or imagery, and unwelcome personal attention.
- Doxxing, or publishing anyone's private information.
- Spam, unsolicited promotion, token shilling, or soliciting funds or private keys.
- Deliberately disrupting discussions, or encouraging others to do any of the above.

## Scope

This code applies in all project spaces (the GitHub repository, its issues, pull requests and
discussions) and when someone represents the project elsewhere.

## Reporting and enforcement

Report conduct problems to **lusca@collider.capital**. Reports are read by the maintainers and kept
confidential; include links or screenshots where you can.

Maintainers decide on a response in proportion to what happened. Responses range from a private
warning, to removing or editing comments, to a temporary or permanent ban from project spaces.
Maintainers who do not follow this code in good faith may face the same consequences.

Security vulnerabilities are not conduct issues; report them as described in
[SECURITY.md](SECURITY.md).
